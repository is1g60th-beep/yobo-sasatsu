# 予防査察アプリ（揖斐郡消防組合の条例・規程対応）

スマートフォン・タブレットで使う予防査察（立入検査）の支援アプリです。サーバー不要の 1 ファイル（`index.html`）で動き、GitHub Pages で公開できます。

## できること

- **対象物の登録と設置義務の判定**：用途（令別表第一）・延べ面積・階数・収容人員・構造などから、必要な消防用設備等と防火管理等の義務を根拠条文付きで表示。
- **査察区分の判定**：揖斐郡消防組合火災予防査察規程 別表第1・第2 による第1種〜第5種と定期査察の回数。
- **公表制度の注意表示**：条例47条の2、規則15条・16条の対象となる設備（屋内消火栓・スプリンクラー・自動火災報知設備）。
- **査察チェックリスト**：対象物ごとに項目を自動生成。「不備」にすると指摘事項（改修文言・根拠・期限）を自動追加。
- **書類作成**：様式第3号 立入検査結果通知書、様式第4号 改修（計画）報告書、様式第5号 勧告書（コピー／印刷用HTMLの保存）。
- **条文検索**：揖斐郡の条例・規則・査察規程・危険物規制規則・要綱の全文（条単位）、消防法令の要旨（e-Gov へのリンク）、主な消防庁告示。
- **違反処理の流れ**：査察規程13〜15条と消防法の命令規定の整理。

## データの保存

査察記録は **使っている端末のブラウザ内（localStorage）だけ** に保存され、サーバーには送信されません。ブラウザのデータ消去で消えるため、「設定 → バックアップ」で定期的に書き出してください。

## 構成

```
index.html            公開用（ビルド済み・この1ファイルで動作）
src/template.html     画面とスタイル
src/logic.js          用途区分・設置義務判定・査察区分・チェックリスト
src/national.js       消防法令の要旨・告示リンク
src/app.js            画面・保存・書類作成・条文検索
data/localtexts.json  揖斐郡の条例・規程本文（条ごと）
tools/build.py        src と data から index.html を生成
tools/build_texts.py  pdf/ の条例PDFから data/localtexts.json を生成（pdftotext が必要）
```

`src/` を編集したら `python3 tools/build.py` で `index.html` を作り直してコミットしてください。条例改正時は `pdf/` に最新PDF（kayojo.pdf など）を置いて `python3 tools/build_texts.py` を実行します。

## GitHub Pages での公開

Settings → Pages → Build and deployment で Source を「Deploy from a branch」、Branch を `main` / `(root)` にすると、`https://<ユーザー名>.github.io/yobo-sasatsu/` で開けます。

## 注意

- 設置義務の判定は主要な基準を簡略化した目安です。令8区画、令32条特例、既存遡及（法17条の2の5）、特定共同住宅・特定小規模施設等の特例基準は反映していません。最終判断は条文・運用基準で行ってください。
- 消防法・施行令・施行規則の内容は要旨であり正文ではありません。
- 様式第3号〜第5号の欄構成は推定です（査察規程PDFに様式図面がないため）。組合の正式様式と照合してください。
